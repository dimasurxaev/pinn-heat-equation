# PINN для уравнения теплопроводности

Решение уравнения теплопроводности с помощью Physics-Informed Neural Networks (PINN) на PyTorch.

## Уравнение

∂u/∂t = α · ∂²u/∂x²

где:
- u(x,t) — температура в точке x в момент времени t
- α = 0.015 — коэффициент теплопроводности

## Условия задачи

| Тип | Условие |
|-----|---------|
| Начальное | u(x,0) = sin(π·x) |
| Граничное левое | u(0,t) = 0 |
| Граничное правое | u(1,t) = 0 |
| Область | x ∈ [0, 1], t ∈ [0, 5] |

## Архитектура нейросети

- 4 скрытых слоя по 50 нейронов
- Активация: Tanh (обеспечивает гладкость, необходимую для вычисления вторых производных)
- Вход: (x, t) — координата и время
- Выход: u(x,t) — температура
